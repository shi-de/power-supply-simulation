# 60_电源仿真

This repository contains the source code, simulation files, and public project documents for **60_电源仿真**.

## Scope

- Embedded firmware and source files are preserved from the project folder.
- Public design documents and templates are included when available.
- Build outputs, caches, archives, videos, local credentials, and temporary work files are excluded.

## Notice

Hardware behavior and simulation results should be verified on the target board and toolchain. Third-party materials retain their original notices and licenses where present.
